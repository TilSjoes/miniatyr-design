# Miniatyr-Norge - how it works

**[SPEC.md](SPEC.md)**: a design description of Miniatyr-Norge, Norway's transport infrastructure in 3D from open
public data, with a Lego-style skin. It covers the data, the rules that turn the data into a landscape, the pyramid
that streams one continuous Norway to a browser, what moves on the map and how far to trust it, the traffic as a test
instrument for the road network, and how it was built.

The map: https://miniatyr.dontpanic.no. The code is not published.

MET Norway, Avinor, adsb.lol, EMODnet and the OpenStreetMap contributors (licences in SPEC.md, section 2).
